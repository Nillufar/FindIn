# Contributing

1. Create a branch from the latest `main`.
2. Work only within your assigned feature area.
3. Validate API input and add tests for business rules.
4. Include a Prisma migration for database changes.
5. Run `npm run build` and `npm test` before opening a pull request.

## Pull request checklist

- [ ] Based on the latest `main`.
- [ ] No secrets or `.env` files committed.
- [ ] Existing tests pass.
- [ ] Relevant SRS requirement referenced.
